# Homepage photography

For now, the homepage photos and videos load directly from newyorkcitywoodfloors.com
(see the `media`, `collections`, `patterns` and `projects` lists at the top of `pages/index.jsx`).

To host them on this site instead, save the files here and change those URLs to `/images/<filename>`.
Any image that fails to load falls back to a warm wood-tone placeholder.

The six finish swatches have no photos yet; they use colour placeholders.
