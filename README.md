# Huggins Wood Floor Specialist — luxurywoodnyc.com

Next.js + Tailwind CSS site for Huggins Wood Floor Specialist.

## Pages
- `/` — homepage: editorial, image-led layout (full-bleed hero, service tiles, the Huggins method, project carousel, testimonials, architects & designers, consultation CTA)
- `/eco-refinishing` — the original eco-friendly refinishing landing page

## Photography
The homepage expects photos in `public/images/`. See `public/images/README.md` for filenames and sizes.
Until a photo is added, a warm wood-tone placeholder is shown in its place.

## Getting started
```bash
npm install
npm run dev
```
Visit http://localhost:3000

## Deploy
Import this repo in Vercel and deploy with defaults.
