# Huggins Wood Floor Specialist — Luxury Architect/Designer Landing Page

This project is a Next.js + Tailwind CSS site for Huggins Wood Floor Specialist, focused on high-end architects and interior designers.

## Quick start

### 1) Install dependencies
```bash
npm install
```

### 2) Run a local preview
```bash
npm run preview
```

Then open:
- http://localhost:3000

> `preview` binds to `0.0.0.0` on port `3000` so it is easy to view from local and containerized environments.

## Other scripts

### Development
```bash
npm run dev
```

### Production build
```bash
npm run build
```

### Start production server (after build)
```bash
npm run start
```
